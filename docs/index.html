claude-code-gateway

Drive Claude Code over HTTP. Keep the limits on the server. Pilotez Claude Code en HTTP. Gardez les limites côté serveur.

An authenticated gateway (JSON and Server-Sent Events) around the Claude Agent SDK. Any program can start an agent run; the server decides which folders, tools, budget and concurrency it gets. Une passerelle authentifiée (JSON et Server-Sent Events) autour de l'Agent SDK de Claude. Tout programme peut lancer un run ; le serveur décide des dossiers, des outils, du budget et de la concurrence.

Quick startDémarrage rapide

You need Node.js 20+ and Claude authentication on the host (claude login, or ANTHROPIC_API_KEY). Il faut Node.js 20+ et l'authentification Claude sur la machine (claude login, ou ANTHROPIC_API_KEY). 

git clone https://github.com/bacarndiaye/claude-code-gateway.git
cd claude-code-gateway
npm install

export GATEWAY_TOKEN=$(openssl rand -hex 32)
export GATEWAY_ROOTS=$HOME/projects
npm start    # http://127.0.0.1:8787
curl -s http://127.0.0.1:8787/v1/run \
  -H "Authorization: Bearer $GATEWAY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"prompt":"Summarise README.md","cwd":"'"$GATEWAY_ROOTS"'","allowedTools":["Read"]}'

Know the limitsÀ savoir

  • No TLS and no multi-user model: one shared token, one trust level. Put it behind an HTTPS reverse proxy and treat the token like a password.Pas de TLS ni de gestion multi-utilisateur : un jeton partagé, un niveau de confiance. Mettez-le derrière un proxy HTTPS et traitez le jeton comme un mot de passe.
  • It runs the real agent. Whatever you add to GATEWAY_ALLOWED_TOOLS is executable on the host; Bash is a shell.Il exécute le vrai agent. Tout ce que vous ajoutez à GATEWAY_ALLOWED_TOOLS s'exécute sur la machine ; Bash est un shell.
  • The test suite uses a fake SDK. The tool cap and the 422 limits were also checked by hand against the real SDK, not in automated tests.La suite de tests utilise un faux SDK. Le plafond d'outils et les limites 422 ont aussi été vérifiés à la main avec le vrai SDK, pas dans des tests automatisés.
